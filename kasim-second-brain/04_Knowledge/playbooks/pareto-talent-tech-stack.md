# Pareto Talent Tech Stack (as of May 2025)

| Tool | Used for | Notes |
|---|---|---|
| Airtable | Source of truth: every client, EA, employee and transaction | About $700/year; automations limited (birthday reminders, 90 and 180 day milestones) |
| GoHighLevel | Sales and marketing, tracking leads and clients | Replaced HubSpot (about $3,000/month) at about $300/month; the first Pareto site and sub-account were free because they shared the agency account |
| ClickUp | Project management: launch a project per client with an onboarding checklist | "My favorite project management tool of all time" (Ivan) |
| WordPress | Website | Moved from GoHighLevel for blogs and site building |
| Lovable | No-code apps, including the matching app; EAs also build their own | Integrated with Airtable and OpenAI APIs |
| ChatGPT | Question generation, "Pareto Consultant" GPT trained on *$100M Offers* | |
| Predictive Index | Assessing EAs to improve matching | Five figures per year |
| Stripe | Payments | About 3% per transaction, no monthly fee; $900 fee added for card payments on annual packages |
| Slack | Team and community communication | Free |
| Facebook ads | Acquiring assistants (about $2,000 for the first cohort) | |

## Flow
1. Sales and marketing in GoHighLevel
2. Once a client closes, the client moves to Airtable
3. A ClickUp project is launched with a checklist for onboarding
4. Matching guidance from the Lovable app; TSM makes the final call
