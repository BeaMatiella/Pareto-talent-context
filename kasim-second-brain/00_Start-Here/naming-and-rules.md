# Naming conventions

- Lowercase, kebab-case: `discovery-call-script.md`
- Dated items start with ISO date: `2026-09-28-podcast-transcript.md`
- Numbered folders keep their order; never rename them.
- Superseded files go to `07_Archive/`, never deleted.

# Confidence tags
- `[TO FILL]` — information still needed
- `[UNVERIFIED]` — came from a source but not confirmed by Kasim
- `[SOURCE: filename]` — cite the raw file a fact came from

# Adding a new file
1. Copy `file-template.md`
2. Fill the frontmatter
3. Save in the right folder
4. Add a line to `index.md`
